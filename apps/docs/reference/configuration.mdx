---
title: "Configuration"
description: "Reference the Hookfish config, runtime options, and environment variables."
---

Define shared broker behavior in `hookfish.config.ts`. Pass runtime-specific behavior as the second argument to `Hookfish.init`.

## Hookfish config

```ts
import { defineHookfishConfig } from '@hookfish/api'

export default defineHookfishConfig({
  db,
  providers,
  includeClient: true,
  includeSwagger: true,
  returnTo: 'https://app.example.com/settings/integrations',
  trustedOrigins: ['https://app.example.com'],
  organizationRouting: false,
  providerManagement: false,
  onEvent: async (event) => auditLog.write(event),
})
```

| Option | Purpose | Default |
| --- | --- | --- |
| `db` | Database or request-aware database binding | Required |
| `providers` | Provider map, registry, or request-aware provider factory | Required |
| `includeClient` | Mount the browser facade at `/api/client` | `false` |
| `includeSwagger` | Include server-only operations in the OpenAPI document | `true` |
| `returnTo` | Fixed destination after an OAuth callback | Development completion page |
| `trustedOrigins` | Origins allowed by per-flow `return_to` values and browser CORS | `[]` |
| `organizationRouting` | Prefix management routes with an organization path | `false` |
| `providerManagement` | Enable dynamic-provider administration | `false` |
| `onEvent` | Best-effort lifecycle and audit event handler | Unset |

## Runtime options

```ts
const hookfish = await Hookfish.init(config, {
  runtime: 'node',
  browserOrigins: ['https://app.example.com'],
  brokerApiKey: (env) => env.BROKER_API_KEY,
  authorizeBrowserRequest: authenticateBrowserRequest,
})
```

| Option | Purpose |
| --- | --- |
| `runtime` | Label returned by `/api/client/health` |
| `browserOrigins` | Runtime-specific override for the browser origin allowlist |
| `brokerApiKey` | Root or scoped credential injected by the browser facade |
| `authorizeBrowserRequest` | Application session and authorization check for browser requests |

## Conventional environment variables

| Variable | Purpose |
| --- | --- |
| `OAUTH_ENCRYPTION_KEY` | Encrypts provider tokens and secret values at rest |
| `BROKER_API_KEY` | Root credential for the Hookfish API and scoped-token signatures |
| `OAUTH_REDIRECT_BASE_URL` | Public origin used to derive provider callback URLs |
| `PGLITE_DATA_DIR` | Local PGlite storage directory |
| `DATABASE_URL` | Direct Postgres connection for Node deployments and local tooling |
| `<PROVIDER>_CLIENT_ID` | OAuth client ID for a built-in provider |
| `<PROVIDER>_CLIENT_SECRET` | OAuth client secret for a built-in provider |

Production deployments must set `OAUTH_REDIRECT_BASE_URL`. Development and test instances may derive it from the incoming request origin.

<Warning>
  Rotating `OAUTH_ENCRYPTION_KEY` makes existing encrypted provider tokens and secrets unreadable.
</Warning>
