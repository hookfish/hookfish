---

Install only the packages required by your trusted server integration.

| Package | Use it for |
| --- | --- |
| `hookfish` | CLI, API scaffolding, packaged frontend, and MCP inspector |
| `@hookfish/api` | API-only `HookfishServer`, config, events, and route types |
| `@hookfish/sdk` | Typed trusted-server client and provider initializers |
| `@hookfish/database` | PGlite, Postgres, and Durable Object adapters |
| `@hookfish/providers` | Built-in provider factories |
| `@hookfish/provider` | Custom provider and registry contracts |

## Database import paths

```ts
import { migrateDatabase } from '@hookfish/database'
import { pglite } from '@hookfish/database/pglite'
import { postgres } from '@hookfish/database/postgres'
import {
  durableObjects,
  HookfishDurableObject,
} from '@hookfish/database/durable-object'
```

The Durable Objects exports are experimental. Use the PostgreSQL adapter with
Hyperdrive for production Workers deployments.

## Trusted server code

Construct `Hookfish` from `@hookfish/sdk`. Put the tenant or organization in
the canonical resource path when your application is multi-tenant.

```ts
import { Hookfish } from '@hookfish/sdk'

const hookfish = new Hookfish({
  apiKey: process.env.HOOKFISH_API_KEY,
  baseUrl: 'https://broker.example.com/api',
})

const github = await hookfish.github(
  'organizations/acme/billing/github',
)
```

Use `hookfish.mcp()` for an authenticated MCP client. The same initializers are
available as `hookfish.provider.github()` and `hookfish.provider.mcp()`.

## Individual provider packages

`@hookfish/providers` re-exports all built-in factories. Install an individual
package such as `@hookfish/provider-github` or `@hookfish/provider-mcp` to keep
the dependency surface narrow.
