---
title: "Organization routing"
description: "Add an explicit tenant key to connection and vault operations."
---

Enable organization routing when each tenant needs a separate request and
database context:

```ts
export default defineHookfishConfig({
  db,
  providers,
  organizationRouting: true,
})
```

Management routes gain an organization prefix:

```text
/api/organization/acme/connections/access/user/personal/github
/api/organization/acme/connections
/api/organization/acme/secrets
```

Callbacks and deployment client metadata stay global:

```text
/api/connections/callback/github
/api/connections/client-metadata.json
```

The organization is stored separately from the connection namespace. It must
be 1–128 characters using letters, numbers, dots, underscores, or hyphens.
Use organization routing for tenant storage selection and broker resource
scopes for per-service authorization; neither replaces application auth.
