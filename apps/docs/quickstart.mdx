---
title: "Quickstart"
description: "Scaffold a Hookfish backend, add one Hono route, and read a Gmail inbox."
---

This guide scaffolds a Hookfish backend, adds a single Hono route to it, and
reads a Gmail inbox through `https://gmail.run.tools`. Hookfish brokers the
OAuth flow, so the route contains no token handling and no error plumbing.

You do not need to create a Google OAuth application. Hookfish uses the MCP
server's OAuth discovery metadata and its supported client-registration
mechanism.

## Prerequisites

- Node.js 20.4 or later
- pnpm
- A Google account with Gmail enabled

<Steps>
  <Step title="Scaffold the backend">
    ```bash
    npm i -g hookfish@latest
    hookfish init my-app --backend node
    cd my-app
    pnpm add @hookfish/sdk hono
    ```

    The scaffold registers the trusted `mcp` and `secret` provider
    implementations and writes gitignored `OAUTH_ENCRYPTION_KEY` and
    `HOOKFISH_API_KEY` values to `.env`. It stores connections in PGlite under
    `data/hookfish`.
  </Step>

  <Step title="Trust the application origin">
    Your route runs on port `8787`, and Hookfish only redirects to origins you
    trust. Add it to `trustedOrigins` in `hookfish.config.ts`:

    ```ts
    trustedOrigins: [frontendUrl, 'http://127.0.0.1:8787'],
    ```
  </Step>

  <Step title="Add the route">
    The generated `src/index.ts` serves the Hookfish API and nothing else.
    Replace it with a Hono application that mounts Hookfish at `/api` and adds
    your own route alongside it:

    ```ts
    import { serve } from '@hono/node-server'
    import { HookfishServer } from '@hookfish/api'
    import { Hookfish } from '@hookfish/sdk'
    import { Hono } from 'hono'
    import config from '../hookfish.config'

    const hookfishServer = await HookfishServer.init(config)
    const port = Number(process.env.PORT ?? 8787)

    const hookfish = new Hookfish({
      apiKey: process.env.HOOKFISH_API_KEY!,
      baseUrl: `http://127.0.0.1:${port}/api`,
      fetch: (request) => hookfishServer.fetch(request, process.env),
    })

    const app = new Hono()
    app.all('/api/*', (c) => hookfishServer.fetch(c.req.raw, process.env))

    app.get('/inbox', async (c) => {
      await using gmail = await hookfish.mcp('user/personal/gmail/mcp', {
        url: 'https://gmail.run.tools',
        returnTo: `http://127.0.0.1:${port}/inbox`,
      })

      return c.json(await gmail.callTool({
        name: 'Gmail_SearchEmailsByQuery',
        arguments: { query: 'in:inbox', max_results: 10 },
      }))
    })

    serve({ fetch: app.fetch, hostname: '127.0.0.1', port })
    ```

    The custom `fetch` dispatches SDK calls straight into the embedded handler,
    so the broker runs in your process without a network hop. Keeping `/api/*`
    mounted exposes the OAuth callback endpoints that the consent flow
    redirects to.
  </Step>

  <Step title="Run it">
    ```bash
    pnpm dev:server
    ```

    Request the route. The connection is not authorized yet, so Hookfish
    returns a fresh consent URL:

    ```bash
    curl -i http://127.0.0.1:8787/inbox
    ```

    ```http
    HTTP/1.1 428 Precondition Required
    Content-Type: application/json

    {"error":{"code":"authorization_required",
              "authorize_url":"https://accounts.google.com/o/oauth2/v2/auth?...",
              "expires_at":"2026-08-16T19:10:00.000Z"}}
    ```

    Open `authorize_url` and approve access. Hookfish stores the encrypted
    credential and redirects to `returnTo`, which renders the inbox.
  </Step>
</Steps>

The route has no `try`/`catch` and no status checks. `hookfish.mcp()` throws
when the connection is not usable, and Hono's default error handler turns that
into the `428` above. See
[how Hookfish works](/concepts/how-it-works) for the full status mapping and
for how to read `user/personal/gmail/mcp`.

This quickstart hardcodes a single-user namespace. In a real application,
derive the namespace from your authenticated session — see
[application authentication](/authentication/application-auth).

<Warning>
  The MCP client receives the usable provider credential. Keep
  `hookfish.mcp()` in trusted server code and never return its results
  directly to a browser without filtering them.
</Warning>
