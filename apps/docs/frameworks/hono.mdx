---
title: "Hono on Node.js"
description: "Mount Hookfish in a Hono application and use typed provider clients from authenticated routes."
---

Use this guide when Hookfish runs inside an existing Node.js application. The
application owns the router and mounts Hookfish below `/api`.

## Install dependencies

```bash
pnpm add @hookfish/api @hookfish/database @hookfish/providers @hono/node-server hono
pnpm add --save-dev tsx typescript
```

## Configure Hookfish

Create `hookfish.config.ts` at the project root. A static provider map gives
the in-process client typed provider methods.

```ts
import path from 'node:path'
import { defineHookfishConfig } from '@hookfish/api'
import { pglite } from '@hookfish/database/pglite'
import { createGitHubProvider } from '@hookfish/providers'

const applicationUrl =
  process.env.APPLICATION_URL ?? 'http://127.0.0.1:3000'

export default defineHookfishConfig({
  db: pglite(process.env.PGLITE_DATA_DIR ?? path.resolve('hookfish-data')),
  includeSwagger: true,
  returnTo: `${applicationUrl}/settings/integrations`,
  trustedOrigins: [applicationUrl],
  providers: {
    github: createGitHubProvider({
      clientId: process.env.GITHUB_CLIENT_ID,
      clientSecret: process.env.GITHUB_CLIENT_SECRET,
    }),
  },
})
```

## Create the server

Mount Hookfish with its mount-relative handler. Keep application routes under
their own paths.

```ts
import { serve } from '@hono/node-server'
import { HookfishServer } from '@hookfish/api'
import { Hono } from 'hono'
import config from '../hookfish.config'
import { requireUser } from './auth'
import { scopedBrokerTokenFor } from './broker-tokens'

const hookfishServer = await HookfishServer.init(config)
const app = new Hono()

app.mount(hookfishServer.basePath, hookfishServer.handler)

const applicationRoutes = app.get(
  '/rpc/github/profile',
  requireUser,
  async (c) => {
    const user = c.get('user')
    const brokerToken = await scopedBrokerTokenFor(user.organizationId)
    const hookfish = hookfishServer.client({ token: brokerToken })
    const github = await hookfish.github(
      `organizations/${user.organizationId}/users/${user.id}`,
    )

    const profile = await github.request('GET /user')
    return c.json(profile.data)
  },
)

serve({
  fetch: app.fetch,
  hostname: process.env.HOST ?? '127.0.0.1',
  port: Number(process.env.PORT ?? 3000),
})

export type ApplicationApi = typeof applicationRoutes
```

`hookfishServer.basePath` defaults to `/api`. `handler` expects paths relative
to that mount, and Hookfish uses the configured base path when it constructs
public OAuth and API URLs. Set `basePath: '/hookfish'` in the broker config to
mount the same server elsewhere.

`hookfishServer.client()` uses trusted in-process dispatch. Pass `token` when
the route needs a tenant-scoped broker credential. Root application code can
omit it.

The initial `hookfish.github()` call throws a Hookfish error when the connection
needs consent or is otherwise unusable. Calls on the returned Octokit client
use Octokit's native API and error behavior.

## Call the application from the browser

Share `ApplicationApi` with the frontend and create a Hono RPC client for your
application routes:

```ts
import type { ApplicationApi } from '../server'
import { hc } from 'hono/client'

export const api = hc<ApplicationApi>('/', {
  init: {
    credentials: 'include',
  },
})

const response = await api.rpc.github.profile.$get()
const profile = await response.json()
```

`requireUser` authenticates the application's session. The scoped broker token
limits the route to the authenticated tenant's namespace. The browser receives
the application result or a safe authorization-required response, never a
broker token or provider access token.

## Run Hookfish separately

When Hookfish runs at another origin, construct the remote SDK client with a
broker URL and credential:

```ts
import { Hookfish } from '@hookfish/sdk'

const hookfish = new Hookfish({
  apiKey: process.env.HOOKFISH_API_KEY!,
  baseUrl: 'https://broker.example.com/api',
})

const connection = await hookfish.connections.get(
  'organizations/acme/github',
)
```

Remote clients expose the universal `connections` surface. Provider methods
come from the server's trusted runtime configuration and are available on
`hookfishServer.client()`.

Continue with [application authentication](/authentication/application-auth)
for the complete security boundary.
