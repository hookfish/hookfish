---
title: "Dashboard and browser access"
description: "Use the operator dashboard and build user-facing connection screens through your authenticated application API."
---

Hookfish includes a static dashboard for adding, viewing, and disconnecting
connections. Treat it as an operator tool. Build user-facing connection
screens against your own authenticated application API.

## Run the packaged dashboard

Generated projects start the dashboard and backend together:

```bash
pnpm dev
```

For an existing backend, serve the packaged dashboard and proxy `/api`:

```bash
pnpm dlx hookfish serve --backend-url http://127.0.0.1:8787
```

The operator dashboard requests a root or scoped broker token and keeps it in
browser session storage. The Add Connection dialog selects a provider first and
uses its metadata to render the remaining controls. OAuth providers render an
authorization action, secret providers render a credential input, and the
input schema renders fields such as an MCP resource name, URL, and scopes.

The dashboard intentionally has no connection-type selector and no generic
vault entry. Provider metadata is the source of truth. Connection lists contain
metadata only and never stored credential values.

<Warning>
  Do not expose the packaged dashboard or a root broker key to your
  application's users. Restrict the dashboard to trusted operators.
</Warning>

## Build a user-facing connection screen

Your application's browser client should call an app-owned route:

```text
Browser
  → authenticated application route
  → scoped server-side Hookfish client
  → Hookfish API
```

The application route verifies the user's session and permissions, maps the
user to a Hookfish resource path, and selects the appropriate scoped broker
token. It can list metadata or disconnect an account, and can call
`connections.access()` only when the route keeps successful secrets server-side.

See [Application authentication](/authentication/application-auth) for the
complete pattern and [React and Hono RPC](/frameworks/react-hooks) for a
browser example.

## Optional browser facade

Hookfish can mount an allowlisted `/api/client` facade with `includeClient:
true`. The facade may expose provider and connection metadata plus disconnect,
but never connection access, authorization starts, secret writes, vault values,
callbacks, or administration. Unlike the packaged operator dashboard, it does
not accept a broker token from the browser to unlock the full API.
