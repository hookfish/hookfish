# Cloudflare Worker example

This example hosts the raw Hookfish API and browser facade on Cloudflare
Workers. It imports the same root `hookfish.config.ts` as the Node examples and
only supplies the Hyperdrive/Postgres database plus Worker host adapter.
Cloudflare runtime and binding declarations are generated by Wrangler; do not
add a handwritten `Env`.

Create a Hyperdrive configuration, place its id in `wrangler.jsonc`, and generate
types:

```sh
pnpm exec wrangler hyperdrive create hookfish-db \
  --connection-string="postgres://user:pass@host:5432/dbname"
pnpm cf-typegen
```

Local development reuses `../../apps/frontend/.env`. Set `DATABASE_URL` to a
direct Postgres connection, then select the Worker from the repository root:

```sh
DATABASE_URL=postgres://user:pass@127.0.0.1:5432/dbname
pnpm dev --backend cloudflare-worker
```

The CLI maps `DATABASE_URL` to Wrangler's local Hyperdrive binding. When
running this package's `pnpm dev` directly, use
`CLOUDFLARE_HYPERDRIVE_LOCAL_CONNECTION_STRING_HYPERDRIVE` instead.

Run migrations with a direct administrative connection, then deploy:

```sh
HOOKFISH_MIGRATION_DATABASE_URL=postgres://user:pass@host:5432/dbname \
  pnpm exec hookfish migrate --backend cloudflare-worker
pnpm deploy
```
