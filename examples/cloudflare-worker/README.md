# Cloudflare Worker example

This example hosts Hookfish on Cloudflare Workers. Its Fetch entrypoint imports
the shared root `hookfish.config.ts`; switch that file from its active PGlite
database to the commented Hyperdrive configuration before running this example.
Cloudflare runtime and binding declarations are generated by Wrangler; do not
add a handwritten `Env` interface.

Create a Hyperdrive configuration, place its id in `wrangler.jsonc`, and generate
types:

```sh
pnpm exec wrangler hyperdrive create hookfish-db \
  --connection-string="postgres://user:pass@host:5432/dbname"
pnpm cf-typegen
```

Local development reuses `../../apps/frontend/.env`. Add the local Hyperdrive
connection string there, then start Wrangler:

```sh
CLOUDFLARE_HYPERDRIVE_LOCAL_CONNECTION_STRING_HYPERDRIVE=postgres://user:pass@127.0.0.1:5432/dbname
pnpm dev
```

Set deployed credentials with `pnpm exec wrangler secret put <NAME>`, run
migrations directly against Postgres, and deploy with `pnpm deploy`.
