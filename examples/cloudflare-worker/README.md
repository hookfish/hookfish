# Cloudflare Worker example

This example hosts the raw Hookfish API and browser facade on Cloudflare
Workers. It imports the root `hookfish.config.ts`, spreads its shared settings,
and replaces `db` with a SQLite-backed Durable Object adapter. Cloudflare
runtime and binding declarations are generated by Wrangler; do not add a
handwritten `Env`. The provider factory receives that generated `env` object
for each request that needs providers, so Worker secret changes are not cached
in global provider clients.

The Durable Object namespace and its SQLite migration are already declared in
`wrangler.jsonc`. Generate runtime types after changing that file:

```sh
pnpm cf-typegen
```

`wrangler-typegen.env` lists secret binding names with empty values solely for
type generation. Store real values with `wrangler secret put`.

Local development reuses `../../apps/frontend/.env`. Select the Worker from the
repository root:

```sh
pnpm dev --backend cloudflare-worker
```

Wrangler persists local Durable Object state automatically. Every object runs
the bundled SQLite migrations lazily on first access. Deploy normally:

```sh
pnpm deploy
```
